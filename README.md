# CarLink (ფაზა 1 — მხოლოდ კითხვა)

ახალი: **ექსპლორერი** ჩანართი, ბენზინის ისტორიის გრაფიკი და ტელეფონის შეტყობინებები (ბენზინი, ძაბვა, გადახურება, ახალი შეცდომა).

Android აპი ELM327 Bluetooth ადაპტერისთვის. აჩვენებს ბენზინს, აკუმულატორის ძაბვას, ძრავის ტემპერატურას,
ბრუნს, სიჩქარეს და შეცდომის კოდებს. კოდების წაშლა (Mode 04) შესაძლებელია დაფიდან, დაცვით (ჟურნალი, მხოლოდ გაჩერებულ მანქანაზე). ფარები/საკეტი ჯერ არ არის.

## გაშვება Windows 11-ზე

1. Android Studio → **Open** → აირჩიე `CarLink` საქაღალდე.
2. დაელოდე Gradle Sync-ს (პირველად რამდენიმე წუთი; ინტერნეტი სჭირდება).
3. თუ Studio შესთავაზებს Gradle/AGP-ის განახლებას, დაეთანხმე ("Update").
4. ტელეფონზე ჩართე Developer options → USB debugging, შეაერთე USB-ით და დააჭირე ▶ Run.
5. აპში დააჭირე **დემო**, რომ მანქანის გარეშეც ნახო ინტერფეისი.

## მანქანაზე ტესტი

1. ტელეფონის Bluetooth-ში დააწყვილე ELM327 (PIN ხშირად `1234` ან `0000`).
2. ჩართე ანთება (ძრავი შეიძლება არ იმუშაოს).
3. აპში: **ადაპტერი** → აირჩიე შენი ELM327 → **დაკავშირება**.
4. თუ რომელიმე მონაცემი "—"-ია, ე.ი. მანქანამ ეს PID არ მოგვცა; ჩაინიშნე და მომწერე.

## შენიშვნები

- ბორბლების წნევა ჯერ არ არის რეალიზებული (საჭიროა Cruze-ის სპეციფიკური მოთხოვნის გამოვლენა).
- პროექტი ჩემ მიერ აგებულია და კომპილაციით ჯერ არ შემოწმებულა; თუ Studio შეცდომას აჩვენებს, გამომიგზავნე.
- ფონური მონიტორინგი და ისტორია შემდეგი ეტაპია.

## მანქანაზე ტესტი ექსპლორერით (ერთხელ, ~5 წუთი, გაჩერებულ მანქანაზე)

1. დაფაზე დაუკავშირდი ადაპტერს (ანთება ჩართული).
2. **ექსპლორერი** ჩანართი → **სრული ტესტი** (ერთი ღილაკი, ~1–2 წუთი).
3. სურვილისამებრ: **მოდულების ძებნა** (700–7FF) — უფრო გრძელია.
4. **გაზიარება** → გამომიგზავნე ლოგი (Telegram/Gmail/სადაც გინდა, ან ჩააკოპირე ჩატში).

ამის მიხედვით ვიპოვით, რომელი მოდულია ხელმისაწვდომი და სად შეიძლება იყოს ბორბლების წნევა.
ბრძანებები (04, 2E, 2F, 31, 27, 10, 11, 14 და ა.შ.) აპში დაბლოკილია.
